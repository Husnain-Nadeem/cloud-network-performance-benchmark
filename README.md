This study benchmarked bidirectional network performance between AWS us-east-1 (Virginia) and us-west-2 (Oregon) using 308 (east→west) and 191 (west→east) iperf3 measurements collected over several days. Round-trip latency (~56 ms) and jitter (~1.2–1.3 ms) were statistically indistinguishable between directions, consistent with a symmetric physical path. However, throughput was significantly asymmetric: west→east averaged 441 Mbps versus 337 Mbps east→west (a 23.7% gap, p < 0.001), accompanied by 43% more TCP retransmissions in the east→west direction (p < 0.001). Packet loss was negligible (0%) in both directions. These results suggest the two directions of this inter-region link are not equivalent in practice, and that throughput-sensitive applications may see measurably better performance sending data from Oregon to Virginia than the reverse.
